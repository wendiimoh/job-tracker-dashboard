# Job Tracker Dashboard

A frontend job application tracking dashboard built with React and TypeScript.

## Features

* Add new job applications
* Delete jobs
* Update application status
* Search and filter jobs
* Dynamic job cards
* Responsive dashboard layout
* Component-based architecture

## Technologies Used

* React
* TypeScript
* Vite
* CSS
* Git + GitHub

## Current Functionality

* Create jobs
* Read jobs
* Update job status
* Delete jobs
* Search jobs

## Future Improvements

* Authentication
* Backend API
* Database integration
* Analytics dashboard
* Dark mode
* Deployment

## Run locally

```bash
npm install
npm run dev
```
